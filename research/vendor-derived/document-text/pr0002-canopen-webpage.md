## 3. 协议说明（原文引用）

> **巨蟹关节模组支持 CAN 2.0 和 CAN FD 通信方式，协议基于 CANopen 402，也称 CiA 402 或 DS402。该协议是 CANopen 协议族中面向驱动和运动控制设备的子协议。**

来源：本页 §3「协议说明」第一段。这段话是判断总线类型的**直接依据**，所以逐字保留：

- 它列举的两种通信方式 `CAN 2.0` 和 `CAN FD` **都是 CAN**。
- 它把协议归入 **CANopen 协议族**（"CANopen 协议族中……的子协议"）。
- 它提到 `CiA 402` / `DS402`，那是**设备行规**（drive profile，规定状态机与对象字典），不是总线。

另外，§3.3「对象字典」说明参数通过 16 bit 索引 + 8 bit 子索引访问，§4 给出的 SDO 报文用的是
11 bit 标准帧 `0x600 + Dev_ID` / `0x580 + Dev_ID`、DLC 8。

## 3.1 通信配置

- CAN FD，标准帧，仲裁段 `1 Mbps`，数据段 `5 Mbps`，启用 BRS
- 执行器 ID 范围 `0x01`–`0x7F`
- 对象字典：16 bit 主索引 + 8 bit 子索引

## 控制模式映射（`6060h` 写入值 → 项目真实模式）

| 写入 `6060h` | 兼容含义 | 项目真实模式 |
|---|---|---|
| `0` | 无模式 | `0` |
| `1` | Profile Position | `1` 轮廓位置 |
| `2` / `3` | Velocity / Profile Velocity | `2` 轮廓速度 |
| `4` / `5` / `10` | Profile Torque / 原生电流 / CST | `5` 电流 |
| `6` | MIT | `6` MIT 阻抗 |
| `7` | 力矩传感器闭环 | `7` |
| `8` | CSP | `3` CSP |
| `9` | CSV | `2` 轮廓速度 |

## SDO 帧（主站 → 从站）

| 字段 | 长度 | 内容 |
|---|---|---|
| StdID | 11 bit | `0x600 + Dev_ID` |
| DLC | | `0x08` |
| `[0]` | 8 bit | 指令码（`2Fh`/`2Bh`/`27h`/`23h` 写，`40h` 读；`60h`/`4Fh`/`4Bh`/`47h`/`43h` 为应答） |
| `[1..2]` | 16 bit | 对象索引，低字节在前 |
| `[3]` | 8 bit | 子索引 |
| `[4..7]` | 32 bit | 写入值，低字节在前 |

从站应答 ID 为 `0x580 + Dev_ID`。

常用序列（以 Dev_ID=1 为例）：

```
2B 40 60 00 06 00 00 00   准备好启动
2B 40 60 00 07 00 00 00   松开抱闸
2B 40 60 00 0F 00 00 00   电机使能激活
2B 40 60 00 80 00 00 00   清除错误
2F 60 60 00 01 00 00 00   设置位置模式
23 7A 60 00 00 40 00 00   设置目标位置
2B 40 60 00 4F 00 00 00   开始绝对运动
```

零位标定：`23 31 25 00 01 00 00 00`（对象 `0x2531`，电机需失能）。

## 自定义 PDO — 单执行器控制报文

| 字段 | 长度 | 内容 |
|---|---|---|
| StdID | 11 bit | `0x100 + Dev_ID` |
| DLC | | `7` |
| `[0].Bit[7]` | 1 bit | 使能：`0` 下使能，`1` 上使能 |
| `[0].Bit[6]` | 1 bit | 抱闸：`0` 吸合，`1` 释放 |
| `[0].Bit[5]` | 1 bit | 清错：`0` 默认，`1` 复位 |
| `[0].Bit[4:1]` | 4 bit | 项目模式值：`1` 轮廓位置，`2` 轮廓速度，`3` CSP，`4` CSV，`5` 电流，`6` MIT，`7` 力矩传感器 |
| `[0].Bit[0]` | | 预留 |
| `[1..2]` | 16 bit | 目标参数 1（位置 `-32768..32767` ↔ `-180..180°`；速度 RPM；电流 mA；力矩 0.1 Nm），Byte[1] 高、Byte[2] 低 |
| `[3..4]` | 16 bit | 目标参数 2（轮廓位置/速度模式下为加减速，`0..20000` RPM/s） |
| `[5..6]` | 16 bit | 前馈参数（位置模式下为输出端轮廓速度） |

示例：`C2 00 00 07 D0 00 05` = 使能 + 抱闸释放 + 轮廓位置模式，目标 `0 cnt`，加减速 `2000`，速度 `5`。

## 自定义 PDO — 多执行器控制报文

StdID `0x200`，DLC `64`：`[0..6]`/`[7..13]`/… 共 8 个 7 字节分包（格式同单轴），
`[56..63]` 为各分包对应的 `Dev_ID`。未使用的分包补 `00`。

## MIT 模式入口

| 入口 | CAN ID | DLC |
|---|---|---|
| PDO4/MIT 固定通道 | `0x500 + Dev_ID` | 8 |
| MIT 单轴快控 | `0x110 + Dev_ID` | 9 |
| MIT 多轴快控 | `0x210` | 64 |

MIT 五元组：位置 16 bit、速度 12 bit、Kp 12 bit（`0..4095` ↔ `0..500`）、
Kd 12 bit（`0..4095` ↔ `0..5`）、力矩 12 bit。**原文没有给出位置/速度/力矩的物理量映射**，
需要实测标定。

## 执行器反馈报文

三种触发：同步帧 `0x80`、多控报文、单轴控制报文。StdID `0x300 + Dev_ID`，DLC `12`：

| 字节 | 内容 |
|---|---|
| `[0..1]` | 负载端实际位置，Byte[0] 高 / Byte[1] 低，`-32768..32767` ↔ `-180..180°` |
| `[2..3]` | 电机端实际速度，int16，RPM |
| `[4..5]` | 实际电流 Iq，int16，mA |
| `[6..7]` | 错误代码 |
| `[8..9]` | 电机线圈温度，int16，0.1 °C |
| `[10]` | 项目模式反馈 |
| `[11].Bit[7]` | 使能状态 |
| `[11].Bit[6]` | 抱闸状态 |
| `[11].Bit[5]` | 报错状态 |
| `[11].Bit[4]` | 位置到位 |

## 编码器

- 电机端 14 bit（`16384 cnt/rev`），负载端 16 bit（`65536` 个位置值，反馈 `0..65535`）
- `position = theta / 360° × 65536`，例：`20° → 3641`
- 过零跳变：正向 `65535 → 0`，反向 `0 → 65535`，全闭环需要补偿
- 16 bit 绝对值编码器角度误差 ≤ ±0.5°，重复定位精度 ≤ ±0.05°

## 11. 其他要点

- 上电约 `300 ms` 进 App，初始化约 `2 s`，完成后上传 `0x700 + Dev_ID`、数据 `00`
- 看门狗帧间隔需 < `500 ms`，否则电机自锁
- 抱闸开合各有约 `100 ms` 延时
- 终端电阻：总线物理两端各一个 `120 Ω`，健康网络主干两端约 `60 Ω`

- CAN 速率对象 `0x2540`：**本文档与 `CANopen-V0.6.xlsx` 定义冲突**，改前先读回确认
